# CC Translate Mac 版

[English](MACOS.md) | [简体中文](MACOS.zh.md)

## 系统要求

- macOS 14 或更新版本，Apple Silicon Mac（M1 或更新芯片）。
- 模型翻译需要已安装、已登录的 Codex CLI 或 Claude Code。
  使用订阅账号登录时，不需要另配付费 API key。
- App 自带运行时，不需要在 Mac 上另外安装 Python。
- 可选本地词典下载后可离线使用，不需要模型账号。

## 安装

1. 打开 [Mac 正式版本页面](https://github.com/mclight-ship-it/cc-translate/releases?q=macos-v&expanded=true)。
2. 在 **Assets** 中下载 Apple Silicon 应用 ZIP，不要下载 GitHub 自动生成的
   **Source code** 源码压缩包。
3. 退出旧版 CC Translate，解压下载文件，将 App 移入“应用程序”，已有旧版时替换。
   尽量只保留一份已安装的 App，避免快捷键和系统权限指向不同副本。
4. 从“应用程序”打开 CC Translate。

Release 同时提供校验和文件。安装包不包含维护者的工作记录、账号凭据、
翻译历史或本地配置。

## 首次启动与权限

**当前版本尚无 Apple Developer ID 签名和公证。** Sparkle 的更新签名用于验证
升级包来自同一个发布者，不等于 Apple 公证，也不能保证系统权限永久保留。

如果 macOS 阻止打开，先确认下载来自本仓库的 Release 页面；若系统提供该选项，
在“系统设置 → 隐私与安全性”中针对这个 App 选择“仍要打开”。
不要全局关闭 Gatekeeper，也不要运行批量移除隔离标记的命令。
如果系统明确报告恶意软件或文件损坏，请停止操作并反馈完整提示，不要绕过。

在“设置 → 快捷键”启用双击 Command+C；使用该快捷键时，需要允许“辅助功能”
和“输入监控”。截图翻译需要“屏幕录制”权限。授权后若未生效，退出并重新打开 App。
只在主窗口输入或粘贴文字，不需要先把所有快捷键权限全部打开。

## 配置翻译服务

按官方说明安装并登录一个 CLI：

- [Codex CLI](https://developers.openai.com/codex/cli)
- [Claude Code](https://code.claude.com/docs/en/setup)

在“设置 → 翻译”选择服务。如果未找到程序，用安装位置控件选择实际的可执行文件。
“已经选择 Codex”只表示选择了服务，不代表程序已安装或账号已就绪。

App 不会代建模型账号、复制凭据或更改账号计费路径。现有 API key 或自定义服务
配置可能产生对应费用；只使用订阅额度时，请使用 CLI 的订阅登录方式。

## 日常使用

- 在其他 App 中选中文字，连续按两次 **Command+C** 翻译。
- 没有可读取的选区时，在快速输入窗口中输入或粘贴文字。一些 PDF 阅读器和受保护
  输入框不会提供可读取的选区。
- 主窗口中输入文字后点击“翻译”，或按 **Command+Return**。
- 启用长文摘要时，先展示摘要，再展示完整译文；后续输出保留阅读位置与文字选区。
- 图片或无法取词的内容可使用截图翻译。本地文字识别不联网；图片模式会将所选图片
  发给配置的模型服务，不是离线翻译。
- 本地词典可在设置中按需下载；词典来源及数据许可与模型生成结果相互独立。
- 历史记录和设置保存在本机，更新 App 不等于卸载并清除数据。

## 在线更新

在 App 中选择“检查更新”。Mac 更新通过 HTTPS 获取信息，并在解压和安装前校验
升级包的 Ed25519 签名。确认更新后，更新器替换已安装 App 并重新启动。
安装了带正式更新渠道的版本后，后续通常无需再次手工下载 ZIP 并拖入“应用程序”。
检查和安装均由用户主动发起，不会静默安装升级。

**旧开发版没有正式更新地址，需要先手工安装一次带更新渠道的正式版。**
没有地址的旧更新器无法自行发现新渠道。

保持 App 安装位置不变。升级应保留设置、历史记录及已下载词典。但当前版本没有
稳定的 Developer ID 签名身份，**升级后 macOS 仍可能重新要求辅助功能、
输入监控或屏幕录制权限**；仅有升级包签名不能消除这个系统限制。

若更新校验或安装失败，保留当前 App，通过 Release 页面恢复；不要关闭签名校验。
反馈问题时请附上 App 版本、macOS 版本和屏幕上的错误，不要上传账号文件或私密原文。
